# 追番台 · AniBT Desk

> [!TIP]
> **[打开项目介绍页 →](https://sen20070910-boop.github.io/anibt-desk/)**
>
> 点击查看订阅新番、选择版本和核对缺集的操作示例。

追番台是给 **Windows 上用 AniBT 和 qBittorrent 追番**的人做的桌面工具。你可以按星期看新番排播，从番剧卡片订阅，给每一部番设定想要的版本，再让后台把符合规则的新集交给 qBittorrent。下载之后，还能在同一个地方查漏集、记看到哪一集，以及保存看完后的评分和评价。

**当前版本 v2.36.3 · Windows x64**

[下载 Windows 便携版](../../releases) · [开始使用](开始使用.md) · [完整手册](使用说明.md) · [发布记录](发布说明.md)

## 一部番是怎么追下来的

1. **从放送表订阅。** 「番剧订阅」按北京时间展示 AniBT 季度排播。确认登录账号与私人 RSS 属于同一账号后，可以在番剧卡片上订阅、取消订阅或打开单番偏好。网站订阅列表也能看到暂时还没有种子的番剧。
2. **先选规则，再交给下载器。** 全局偏好可以给每部番继承，单番再覆盖发布组、画质、字幕形式、开始日期或集数、下载目录。默认要求含简中，并以第一次读到的资源为基线，后续符合条件的新发布才进入自动下载。保存规则前可预览筛选结果和等待原因。
3. **下载新集、手动补旧集。** 后台定时检查 AniBT 私人 RSS，通过 Web UI 向 qBittorrent 提交任务。使用本机 qBittorrent 时，可以在有任务要提交时自动启动它。旧集可以从「已有资源」挑版本，也可以从「追番进度」按缺集编号跨站搜索，核对后再提交。
4. **看完之后留一份自己的记录。** 手动标记进度，把完结作品收进「我看过的」，写评分和观后评价，或开启新一轮重看并保留历次评价。观看档案保存在本机，也可以随迁移备份导出。

## 三个可以直接用到的场景

| 你遇到的情况 | 在追番台怎么做 |
| --- | --- |
| 追到第 5 集才开始用，想从这里接上 | 在这部番的单独设置里填开始集数 `5`，预览规则后启动后台。已经发布、想补的集数在补下载窗口逐集勾选。 |
| 想优先等 A 组简中，过几小时也接受 B 组 | 把 A 组放到优先级首位，允许组里保留 B 组，设定等待时长。符合规则的 B 组先排队，等待结束后可补位。同番同集同修订版默认只提交一份。 |
| 离线几天，回来看起来少了一集 | 在追番进度里跑离线漏集核对或点缺集编号。核对分季、集号和版本，选择可用的 RSS 候选或跨站搜索结果，确认后加入 qBittorrent。 |

## 和同类工具怎么选

追番台把 **AniBT 站内订阅、Windows 上的 qBittorrent 下载和本机逐集观看记录**接在一起。它适合想在自己的电脑上管理追番、按每部番选版本，并在断更或离线后手动核对漏集的人。下面按各项目公开文档介绍的工作流对照。

| 工具 | 擅长的工作流 |
| --- | --- |
| **追番台** | 在 Windows 原生桌面窗口浏览 AniBT 排播和订阅，从私人 RSS 按规则提交给 qBittorrent。随手查漏集、按集选版、记录看完与重看。 |
| AutoBangumi | 接入不同站点或聚合 RSS，自动生成下载规则，按媒体库结构整理与重命名文件。适合把文件整理进 Plex、Jellyfin 等媒体库。[项目文档](https://github.com/EstrellaXD/Auto_Bangumi) |
| ani-rss | 围绕 RSS 订阅自动下载，提供刮削和洗版。适合关注媒体元数据以及更新已入库发行版本的人。[项目文档](https://github.com/wushuo894/ani-rss) |
| Animeko | 把多来源播放、弹幕、离线缓存和 Bangumi 观看记录同步放在同一个客户端。适合以找番、看番和弹幕体验为主的人。[项目文档](https://github.com/open-ani/animeko) |

## 日常管理

- **版本与重复任务。** 自动追番、发现资源与已有资源使用同一套番剧和集数去重依据。确实想收藏同集多个版本时，可以在手动添加前明确允许本次多版本。`v2` 等修订版按修订号区分。
- **目录与后台。** 默认把新任务分到各自的番名子目录。关闭桌面窗口后，已开启的后台仍可检查 RSS、提交任务并报告下载完成或异常。下载和做种由 qBittorrent 管理。
- **多站找资源。** 「发现资源」可查 AniBT、Anime Garden、蜜柑计划、动漫花园、Nyaa、VCB-S 作品、ACG.RIP、萌番组、nekoBT 和 SeaDex。模糊搜索同时查询番剧别名，也能查到第一季未标季号的发布。查到相同种子哈希时自动合并来源。SeaDex 标注完结番的首选和备选版本。VCB-S 官网受验证阻挡时，页面会标明替代来源。
- **合集按文件下载。** 发现资源里可预选正片、简中外挂字幕和配套字体，按需勾选音轨或特典，再确认下载。使用支持添加前读取清单的 qBittorrent Web API（2.11.9 或更新版本）。
- **动漫排行与四站评分。** 「动漫排行」提供四站综合榜与 Bangumi、MyAnimeList、AniList、豆瓣的单站榜。剧集和动画电影综合榜各展示前 200 名，至少三站有评分才能上榜。未上榜的作品也能通过「搜索评分」查询四站原始分数。
- **记录与备份。** 跨机迁移用可导出的 JSON 备份，导入时可以调整下载目录。私人 RSS 和 qBittorrent 密码需要在新设备单独填写。同一 Windows 账户和安装目录可以使用加密的本机状态快照。

## 下载与首次配置

1. 在 [Releases](../../releases) 的 **Assets** 下载 `AniBT-qB-v版本号-Windows-x64.zip`，完整解压。当前便携包附带 Node.js，适用 Windows 10/11 x64。
2. 在 qBittorrent 的「工具 → 选项 → Web UI」启用 Web UI，记下地址、端口、用户名与密码。只在同一台电脑使用时，可以监听 `127.0.0.1`。Windows 缺少 WebView2 Runtime 时请先安装。[微软 WebView2 下载](https://developer.microsoft.com/microsoft-edge/webview2/)
3. 双击「打开图形界面.vbs」。在偏好设置里填入你自己的 AniBT 私人订阅 RSS 和 qBittorrent 连接信息，保存并测试连接。可以双击「创建桌面快捷方式.vbs」添加桌面入口。
4. 到「番剧订阅」选一部想追的番，按需要设置单番偏好。回到总览点击「启动自动追番」。第一轮会记录已有资源，需要旧集时，可以先预览再确认补下载。

这个版本是未签名的 Windows 便携测试版。附件中的 `.sha256` 可以用来核验下载文件。应用内版本检查可以读取配置好的公开 GitHub Releases 并显示版本和发布页。完整操作和故障排查见 [使用手册](使用说明.md)。

## 开发构建

开发环境需要 Node.js >=22.19.0。完整构建会从锁文件安装依赖，构建 JavaScript 和 Windows 桌面壳，生成便携包并测试解压后的启动。[工程与打包说明](ENGINEERING.md)

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/clean-build-check.ps1
```

桌面壳使用固定版本的微软 WebView2 SDK，构建脚本从官方来源获取工具链并校验哈希。发布请使用脚本生成的 ZIP 和校验文件。便携包按文件清单组装，并检查本机私人配置、记录及凭据是否混入。

## 命令行示例

```powershell
.\anibt-qb.cmd --help
.\anibt-qb.cmd init
.\anibt-qb.cmd doctor
.\anibt-qb.cmd preview
.\anibt-qb.cmd watch
```

GUI 与命令行共用配置和记录。私人配置保存在本机，qBittorrent 密码由当前 Windows 账户加密。
