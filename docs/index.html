一部番怎么追下来

以一部已经播到第 5 集的新番为例。

  1. 从放送表订阅

    按季度和星期浏览，找到要追的番。在卡片上登录并确认订阅 AniBT，然后给这部番设定从第 5 集开始追。

  2. 先等喜欢的版本

    限定画质和字幕形式，把 A 组设为首选，B 组列为可补位。规则预览会显示哪些条目符合、哪些在等待。

  3. 有更新就交给 qBittorrent

    后台定时读取 AniBT 私人 RSS。默认同番同集同修订版只提交一份。启用按需启动后，本机 qBittorrent 在有任务时可自动打开。

  4. 查漏、看完、收档

    打开追番进度核对遗漏的集数，选定资源再补下载。看完可打分、写评价，重看时保留以前的观看记录和评价。

开始使用

准备 AniBT 账号、能连接的 qBittorrent Web UI，以及带 WebView2 Runtime 的 Windows 10/11 x64 电脑。

自动追番使用 AniBT 私人 RSS。手动补集可在「发现资源」搜索 Anime Garden、蜜柑计划、动漫花园、Nyaa 等来源，也能同时查找番剧别名。

  1. 下载 Windows x64 ZIP 并完整解压。
  2. 开启 qBittorrent 的 Web UI，然后双击「打开图形界面.vbs」。
  3. 在偏好设置填入自己的 AniBT 私人 RSS 和 qBittorrent 连接信息，测试成功后启动自动追番。
